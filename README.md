# Bank-customer-churn-analysis
Bank Customer Churn Analysis Dashboard
📌 Project Overview

This project focuses on analyzing customer churn behavior in a banking environment using Power BI.
The dashboard helps identify who is leaving, where they are leaving from, and potential engagement gaps.

🎯 Objectives

Measure overall customer churn rate

Identify high-risk customer segments

Analyze churn by gender and geography

Support data-driven retention decisions

📈 Key Metrics

Total Customers

Churned Customers: 2,038

Churn Rate: 20.38%

Customer Distribution by Geography

Credit Card Ownership by Gender

🔍 Key Insights

Female customers exhibit higher churn compared to males

France has the largest customer base and churn concentration

Customers with credit card engagement show better retention

Geography plays a significant role in churn behavior
